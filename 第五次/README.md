# 实验五 · 听见回响

## 目标与范围

验证 I.MX6ULL ALPHA 的 WM8960 音频通路：检查 ALSA 声卡和混音器，播放测试旋律，通过板载麦克风录音十秒，再回放录音。使用开发板既有的 WM8960、SAI、ASRC 与 ALSA 驱动；本实验没有重新移植驱动、编译内核或更换设备树。

## 过程与文件

1. 查看声卡设备、混音器控件和实际音频路由，记录基线配置。
2. `playback_config.sh` 设置播放通路，`mic_config.sh` 设置麦克风输入，实测使用 `left1`。
3. `tools/make_music.py` 生成 6.4 秒原创测试旋律，素材为 `音频/lab5_music.wav`。
4. `run_on_board.sh` 顺序执行播放、十秒录音、回放和配置保存。
5. 从串口取回原始录音，使用 `tools/verify_audio.py` 校验 PCM、时长和哈希。

```sh
# 将脚本和音频部署到开发板独立目录后执行
cd /home/root/lab5
sh run_on_board.sh
```

具体参数与配置恢复步骤见 `实验步骤.md`。新录音使用带日期和进程号的文件名，板端系统时钟不准确，不能依此确定实验日期。

## 结果与证据

播放、录音、回放退出码均为 0，现场确认旋律与录音回放均可听见。核心证据为 `实测记录/09_播放录音回放实测.txt`、`音频校验.json`、`现场确认.md` 与 `音频/mic_left1.wav`。`mixer-before.state` 和 `mixer-lab5.state` 分别记录原配置与实验配置。

原始录音音量较低；左右声道相同来自 `ADC Data Output Select` 将左 ADC 送到两个声道，不代表两路独立麦克风采集。`right2` 未实测。系统已有开机恢复声卡设置服务，本次保存了配置，但没有验证重启后的效果。

历史失败和排查日志按时间保留，`evidence.zlib` 压缩包未上传，其已解出的音频与文本证据分别收录。
