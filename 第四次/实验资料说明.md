## 资料重点与使用条件

1. 每次实验前检查虚拟机网络是否已连接，并验证开发板与虚拟机之间的网络连通性。
2. NFS 用于让开发板访问虚拟机提供的文件；具体共享目录与挂载方式需要按实际环境配置。
3. 如果加载模块出现 `disagrees about version of symbol` 或 `Unknown symbol ... (err -22)`，需要检查板上运行内核与编译模块所用内核构建及 `Module.symvers` 是否匹配。仅版本字符串同为 4.1.15、编译器相同或文件时间戳较新，不能证明构建匹配。
4. PDF 给出的替代驱动使用 `miscdevice`，硬编码 GPIO5_IO01 的旧式全局编号 129，低电平响、高电平关。该方案依赖正确的引脚复用、GPIO 编号与硬件电路；更换接口不能保证修复内核符号版本不匹配。
5. 示例驱动接收单字节二进制命令：`0x01` 开启，`0x00` 关闭。直接写入文本字符 `1` 或 `0` 不等于上述二进制命令。PDF 中的 `echo -ne` 命令是否可用取决于目标系统 shell 的实现。
