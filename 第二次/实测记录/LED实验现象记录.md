# 裸机 LED 实验现象记录

实验日期：2026 年 10 月 16 日（北京时间）

## 已完成：第十章 C 语言 LED，延时参数 500

- 开发板：依据此前环境记录，为正点原子 I.MX6ULL ALPHA。
- 程序：`工作工程/c_500`，循环中开、关灯后均调用 `delay(500)`。
- 编译：在 WSL 2 的 sweet 发行版中交叉编译成功，ARM GCC 13.3.0。
- 烧录：向已识别的 USB SD 卡原始偏移 1024 字节写入 3660 字节启动镜像，并读回校验一致；原始前 4MiB 已备份。
- 烧录时间：2026-10-16 12:09:04（北京时间，由烧录日志 UTC 时间换算）。
- 板上操作：指导用户断电、插入 SD 卡、按实物板标注设置 SD 启动并重新上电。
- 现场反馈：用户在本次对话中明确回复“闪烁”。
- 结果：依据用户现场观察，C 语言默认延时版本的 LED 闪烁效果已确认。
- 证据边界：本记录依据编译及烧录日志和用户文字反馈；尚无现场照片或视频，未测量实际亮灭周期，不能写成精确的 500ms 延时实测。

## 已完成：C 语言 LED，延时参数 3000

- 程序：`工作工程/c_3000`，开、关灯后均调用 `delay(3000)`。
- 烧录时间：2026-10-16 12:17:07（北京时间）。
- 目标：重新核实后的 USB SD 卡 `/dev/sde`，容量 31,270,109,184 字节。
- 烧录结果：在偏移 1024 字节处写入 3660 字节，读回校验一致，写入范围外的前 4MiB 数据保持不变。
- 镜像 SHA-256：`d92438d0577f026af293cb7be2fd94f35f0afe8f508f2da6f2f8f5e812174422`。
- 现场反馈：用户上电观察后明确回复“明显亮和熄灭的时间更长了”。
- 结果：依据用户现场观察，3000 版本相较 500 版本的亮、灭持续时间明显增加，慢闪效果已确认；未计时测量实际周期。

## 已完成：第八章汇编 LED 常亮

- 程序：`工作工程/asm_on`，向 GPIO1_DR 写入 0，使 GPIO1_IO03 输出低电平，随后进入死循环。
- 烧录时间：2026-10-16 12:24:09（北京时间）。
- 目标：重新核实后的 USB SD 卡 `/dev/sde`，容量 31,270,109,184 字节。
- 烧录结果：偏移 1024 字节处写入 3232 字节，读回校验一致，写入范围外的前 4MiB 数据保持不变。
- 镜像 SHA-256：`ff9b8592832e61dc1fd54b7c83069debfc08247811d7e1fc7893d3cedbdd32d8`。
- 现场反馈：在告知预期为“用户 LED 一直亮，不再闪烁”后，用户回复“符合预期”。
- 结果：依据用户现场反馈，汇编常亮效果已确认。

## 已完成：第八章汇编 LED 熄灭

- 程序：`工作工程/asm_off`，将常亮版本的 `ldr r1, =0` 改为 `ldr r1, =8`，向 GPIO1_DR 写入 8，使 GPIO1_IO03 输出高电平，随后进入死循环。
- 烧录时间：2026-10-16 12:26:28（北京时间）。
- 目标：重新核实后的 USB SD 卡 `/dev/sde`，容量 31,270,109,184 字节。
- 烧录结果：偏移 1024 字节处写入 3232 字节，读回校验一致，写入范围外的前 4MiB 数据保持不变。
- 镜像 SHA-256：`c326cb8568830db8f5a412671dad868e91f9cdcce7a92d8b3e6981aa4ae60724`。
- 现场反馈：在告知预期为“电源指示灯正常亮，用户 LED 始终熄灭”后，用户回复“符合预期”。
- 结果：依据用户现场反馈，汇编熄灭效果已确认。

## 实验复盘

在 WSL 2 环境中完成 C 语言裸机 LED 程序的交叉编译，将启动镜像烧录至 SD 卡并完成读回校验。按 SD 卡启动流程操作开发板后，现场观察到用户 LED 持续闪烁。将两处延时参数由 500 改为 3000，重新编译、烧录并上电后，LED 亮和灭的持续时间明显增加，闪烁速度变慢，验证了延时参数对闪烁速度的影响。实际闪烁周期未进行计时测量。

## 补充说明

Windows 中 F 盘目录为空不代表烧录失败。本实验将启动镜像写入 SD 卡原始区域，不会在文件目录中显示为普通文件。

四组程序均已完成交叉编译、SD 卡烧录和读回校验，用户逐组确认了板上效果：C 语言默认闪烁、增大延时后慢闪、汇编常亮及汇编熄灭。现场效果依据用户文字反馈，未收到现场视频，未测量闪烁周期。当前 SD 卡保留汇编熄灭版本。第十章 C 语言 LED 实验以默认闪烁与慢闪对比为重点。
