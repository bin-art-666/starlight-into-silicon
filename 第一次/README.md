# 实验一 · 初识微光

## 目标与环境

搭建并检查嵌入式开发环境，理解串口和 U-Boot 的作用，完成 Linux C 程序的编写、编译、运行与调试。实测采用 Windows + WSL 2（发行版 sweet / Ubuntu 24.04 / x86_64），使用 GCC、Make、GDB 等工具。

## 实验过程

1. 检查 WSL、编译器和调试器版本，记录见 `实测记录/WSL环境实测.txt`。
2. 检查 CH340 串口驱动与串口参数（历史为 COM3、115200、8N1）。连接开发板，区分 Linux 启动输出、U-Boot 命令行与原始二进制显示。
3. `C语言实验/scores.c` 读取五个 0—100 的分数，输出平均分、最大值及及格人数。程序使用 `strtod`，检查空输入、尾随无效字符、数值范围及非有限数。
4. 编译运行并执行九组输入用例验证，全部通过；GDB 在 summarize 断点查看参数与成绩值后继续正常退出，保留 `experiment.log`、`gdb.log` 与 `test_results.json`。

```sh
cd C语言实验
make
./scores < normal.in
python3 test_scores.py
```

## 结果与排查经验

环境与运行结果见原始日志；串口相关证据包括 `01_CH340设备状态.png`、`02_串口参数.png`、`03_二进制显示问题.png` 和 `04_Linux启动成功.png`。区分“串口未连接”“波特率不匹配”和“终端采用二进制显示”后再判断故障。
