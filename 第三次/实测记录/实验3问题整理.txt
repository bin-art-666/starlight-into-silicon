问题3：eth0 与 eth1 网口混淆
现象：
  使用 eth1 启动时，NFS 挂载失败；
  使用 eth0 后成功启动。
原因：
  开发板存在两个网口（ENET1 / ENET2）；
  教程默认使用 ENET2（FEC1 → eth0）；
  内核中虽然注册了 eth1，但设备树中 FEC1 默认未启用。
解决方法：
使用 ENET2 网口，并在 bootargs 中写：
 setenv bootargs 'console=ttymxc0,115200 root=/dev/nfs \
 nfsroot=192.168.10.100:/home/alientek/linux/nfs/rootfs,proto=tcp rw \
 ip=192.168.10.50:192.168.10.100:192.168.10.1:255.255.255.0::eth0:off'


注意最后是 eth0:off


最终确认
   使用 ENET2 网口（FEC1 → eth0）；
   bootargs 中必须为 eth0:off ；
