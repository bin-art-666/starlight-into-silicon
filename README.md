# 星火入芯 · Starlight into Silicon

> 从一盏灯的明灭，到声音与窗口的回应，把求知的星火写进芯片。

基于 **正点原子 I.MX6ULL ALPHA** 的七次嵌入式系统实验学习档案，收录源码、构建脚本、运行日志、原始截图、参考例程和复盘总结。实验记录主要来自 2026 年 10 月 12—16 日；本仓库于 2026 年 10 月 26 日整理，整理时没有重新执行硬件实验。

## 环境与阅读顺序

- 主机：Windows + WSL 2，Ubuntu 24.04；不同实验实际编译器版本见各目录。
- 开发板：I.MX6ULL ALPHA，512 MiB DDR，实测 Linux 内核 `4.1.15-g3dc0a4b`。
- 串口历史配置：CH340、COM3、115200、8N1；端口号应重新检测。
- 网络历史配置：ENET2 接电脑网卡，电脑 `192.168.1.100/24`，开发板 `192.168.1.4/24`；这些是实验局域网地址。
- 实验六运行于桌面 x86_64 Qt；实验七运行于开发板 ARM Qt，二者构建环境不同。

先阅读每个目录的 `README.md`，再看源码和 `实测记录/`。原始过程文档保留了历史失败与阶段状态，最终结论以对应 README 指定的完成记录为准。旧日志中的“当前”“下一步”和进程号均指当时状态。
